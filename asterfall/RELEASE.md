First playable: actual 3D Java action RPG with cute pastel characters, melee/ranged/area attacks, dodge, loot, equipment, talents, boss, replayable expeditions, and saves. Local time and weather (default 11355) influence lighting and modest loot bonuses.

**Download Asterfall-Windows.zip, extract the entire ZIP, and run Asterfall.exe. Java is bundled.** The source ZIP is for development and future updates.

Windows 10/11 x64 and an OpenGL-capable graphics driver required. Unsigned prototype executable. Render/combat checks passed on Linux; Windows launcher remains to be playtested. See START-HERE.txt inside the ZIP for controls and troubleshooting.
