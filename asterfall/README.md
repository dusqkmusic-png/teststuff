# Asterfall — The Crowned Garden

A first playable Java desktop action RPG with actual polygonal 3D characters,
pastel environments, combat, randomized equipment, talents, a boss, saves,
and local time/weather effects. This lives separately from the Willowmere
browser game at the repository root.

## Download and play (Windows 10/11, 64-bit)

[**Download Asterfall-Windows.zip**](https://github.com/dusqkmusic-png/teststuff/releases/download/asterfall-v0.2.0/Asterfall-Windows.zip)

Extract the **whole ZIP**, then run **Asterfall.exe**. Java is included.
The download becomes available when the first Asterfall workflow succeeds.
[Build status and downloadable artifacts](https://github.com/dusqkmusic-png/teststuff/actions/workflows/asterfall.yml).

WASD moves relative to the overhead camera; left mouse swings the sword; Q sends a sword shockwave; E performs a whirlwind; Space dodges;
R drinks a potion; F collects/rests; I opens equipment; K opens talents;
Esc pauses; F1 opens the complete guide. Read START-HERE.txt for details.

Weather defaults to 11355 (Flushing, Queens), and can be changed in Settings.
Your computer clock controls local time. Matching conditions give a small loot
weight bonus; no items are locked to particular times or weather.

This is a small original prototype, with one class and a replayable garden/boss
loop. It is not a full Diablo-scale game. Linux render/gameplay checks pass;
the cross-built Windows launcher still needs Windows playtesting.

## Development

Run `python3 fetch_dependencies.py`, then `python3 make_assets.py` on Linux with
Pillow and DejaVu Sans installed, then `python3 build.py` with Java 17+.
The workflow generates assets, builds, tests saves/loot/equipment/weather logic,
and packages the game with a checksum-verified Windows runtime. See DEVELOPMENT.md.

Items and encounter areas live under content/. Keep item IDs stable for saves.
No saves or credentials are committed. Third-party notices are in THIRD-PARTY.txt
and licenses/. Character meshes, scenery, sound effects, and music are original
procedural assets generated by the included code.
